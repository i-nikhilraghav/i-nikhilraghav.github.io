# Personal Portfolio Website – Nikhil Raghav

## Overview

This is a modern, responsive **personal portfolio website** for Nikhil Raghav. It showcases skills, projects, and contact information using a clean, interactive, and visually appealing design. The site features **three themes** (Light, Dark, Ocean) for an enhanced user experience and is fully **mobile-friendly**.

Built with **HTML, CSS (TailwindCSS), JavaScript**, and **Font Awesome** for icons, this portfolio demonstrates best practices in front-end development.

---

## Features

* **Responsive Design:** Works seamlessly on desktop, tablet, and mobile devices.
* **Theme Toggle:** Switch between Light, Dark, and Ocean themes.
* **Smooth Scrolling:** Navigation links scroll smoothly to sections.
* **Interactive Skill Bars:** Animated skill bars display proficiency levels.
* **Fade-in Sections:** Sections appear with a smooth fade-in animation as you scroll.
* **Glassmorphism Cards:** Stylish glass-effect cards for content sections.
* **Mobile Menu:** Collapsible mobile navigation menu with easy toggling.
* **Accessible Design:** Clear typography, buttons, and color contrasts for readability.

---

## Sections

1. **About Me:** Brief introduction and personal information.
2. **Skills:** Shows proficiency in various technologies with animated skill bars.
3. **Projects:** Highlights recent or featured projects.
4. **Contact:** Provides ways to get in touch.

---

## Technologies Used

* **HTML5 & CSS3**
* **JavaScript (ES6)**
* **Tailwind CSS** – utility-first CSS framework for rapid styling.
* **Font Awesome** – icons for UI elements.
* **Google Fonts** – Inter and Poppins fonts for typography.

---

## Installation & Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/i-nikhilraghav/portfolio-website.git
   ```
2. Open the `index.html` file in your preferred web browser.
3. Optionally, host it on **GitHub Pages**, **Vercel**, or **Netlify** for live access.

---

## Customization

* **Themes:** Modify CSS variables under `:root` or add new themes.
* **Skills:** Update the skill percentages and names in the Skills section.
* **Projects:** Add or edit project cards under the Projects section.
* **Contact:** Replace placeholder information with your real contact details.
